# MIRA — Applied Agentic AI for Technical Program Managers (TPMs)

MIRA (Mira Agent) is a demonstration of an agentic AI assistant designed to help Technical Program Managers streamline project planning, produce actionable status reports, and monitor progress through Trello integrations. This repository holds the capstone deliverables: visuals, exported artifacts, and the presentation used to showcase the project.

TL;DR
- Purpose: Convert raw project specifications into structured project plans, scan Trello boards for real‑time status, and generate concise weekly reports for TPMs.
- Audience: Technical Program Managers, engineering leaders, and anyone exploring applied agentic AI for program management.
