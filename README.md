# MIRA — Applied Agentic AI for Technical Program Managers (TPMs)

MIRA (Mira Agent) is a production-oriented demonstration of an agentic AI assistant built to help Technical Program Managers automate project planning, generate status reports, and track real-time progress through Trello integrations. This repository contains the deliverables, artifacts, screenshots, and the final presentation produced for the capstone submission.

TL;DR
- Purpose: Showcase a working pipeline that converts raw project specifications into a structured project plan, monitors Trello boards, and produces weekly scans and reports for TPMs.
- Audience: TPMs, engineering leads, data scientists, and anyone evaluating applied agentic AI for program management.
